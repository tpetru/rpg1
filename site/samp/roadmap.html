🚀 PLANNED IMPROVEMENTS

Upcoming

Features and enhancements under consideration for future updates:

  • Cement Truck Driver redesign — make the job more engaging with varied deliveries and rewards
  • Caravan detach restriction — require /detach only near player's house (50m radius)
  • Lumberjack dedicated vehicles — add a depot with company trucks instead of requiring model 433
  • Lumberjack job locations — add work start/end locations to locations_admin table for Lumberjack job
  • Forest ownership system — allow players to own and manage forests, replant trees instantly once per day
  • Additional job slots — system supports slots 13-20, ready for future jobs
  • Expanded store types — more specialized shops for late-game players
  • Dynamic weather — seasonal changes affecting farming and outdoor activities

📋 TEMPORARY TEST FLAGS

Monitoring

These are temporary settings used during development and testing. They may be adjusted as needed:

  • Golf/Basketball — currently accept 1+ players (may raise minimum when population grows)
  • Territory wars — require 2+ faction members (currently configurable)
  • Drug smuggling crew minimum — normally requires 2+ members in vehicle
  • Hour restrictions — certain jobs have time windows that can be temporarily adjusted for testing
These flags don't affect gameplay balance but allow admins to test with small player counts. Full restrictions will be enforced with mature server population.
